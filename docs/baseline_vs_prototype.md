# Baseline vs Collaborative Prototype Comparison Matrix

| Evaluation Dimension | Traditional Attendance Baseline | Collaborative Outcome Tracker | Why Collaborative Tracker is Superior |
| :--- | :--- | :--- | :--- |
| **Primary Metric** | Attendance rate (Attended / Scheduled sessions) | Client-defined goal progress percentage | Measures actual functional recovery rather than room presence. |
| **Goal Source** | Clinician / System mandate | Dual Client + Clinician collaborative definition | Enhances client engagement and self-efficacy. |
| **Baseline & Target** | Implicit assumption (100% attendance target) | Explicit numerical baseline, target, unit, & method | Provides clear, objective progress benchmarking. |
| **Evidence Capture** | Absence / Presence timestamp | Behavioral evidence notes & self-confidence rating | Validates real-world behavioral changes outside clinic. |
| **Barrier Logging** | Marked as "Did Not Attend" (DNA) | Structured barrier severity & resolution tracking | Uncovers root causes preventing client recovery. |
| **Interventions** | Rebooking missed slots | Dual agreed adjustments (Client + Clinician) | Tailors support to client obstacles with consent. |
| **Follow-Up Ownership** | Shared unassigned clinic queue | Specific owner role & owner ID assignment | Establishes direct personal accountability. |
| **Due Date Enforcement** | None | Hard due dates with automated overdue detection | Prevents follow-up tasks from slipping through cracks. |
| **Escalation Rules** | Case closure after N missed sessions | 3-Level automated governance escalation | Retains overdue items until explicitly resolved. |
| **Privacy Protection** | Full EHR diagnosis & detailed notes | Synthetic IDs & non-diagnostic categories | Minimizes sensitive data exposure by design. |
